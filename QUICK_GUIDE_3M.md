# 🚀 Быстрый старт для 3.8M доменов

## Проблема: 3.8M доменов → ~105 дней сканирования без фильтрации

## Решение: mass_filter.sh - автоматическое разбиение и параллельная фильтрация

---

## 📋 ТРИ СПОСОБА (выберите один):

### Вариант 1: Ручное разбиение (простой)

```bash
cd /home/kiki/disk30gb/cpsniper

# 1. Разбить на части по 100K доменов
split -l 100000 woo_domains.txt woo_domains_part_

# Получится 38 файлов:
# woo_domains_part_aa, woo_domains_part_ab, ... woo_domains_part_bm

# 2. Запустить фильтрацию первой части (тест)
./cPanelVulnFinder.sh woo_domains_part_aa vulnerable_part1.txt

# 3. Запустить фильтрацию всех частей (4 параллельно в разных терминалах)
# Терминал 1:
./cPanelVulnFinder.sh woo_domains_part_aa filtered_aa.txt

# Терминал 2:
./cPanelVulnFinder.sh woo_domains_part_ab filtered_ab.txt

# Терминал 3:
./cPanelVulnFinder.sh woo_domains_part_ac filtered_ac.txt

# Терминал 4:
./cPanelVulnFinder.sh woo_domains_part_ad filtered_ad.txt
```

**Время:** ~2 часа для всех частей
**Результат:** ~10K фильтрованных таргетов

---

### Вариант 2: Автоматическое (рекомендуется)

```bash
cd /home/kiki/disk30gb/cpsniper

# Запустить автоматический разбиение и фильтрацию
./mass_filter.sh woo_domains.txt

# Скрипт сам:
# 1. Разобьет на части
# 2. Запустит 8 параллельных процессов фильтрации
# 3. Будет показывать прогресс в реальном времени
# 4. Объединит результаты в один файл
```

**Время:** ~30-40 минут для всего
**Результат:** filtered_results/all_vulnerable_targets.txt

---

### Вариант 3: Быстрый старт (минимум команд)

```bash
cd /home/kiki/disk30gb/cpsniper

# Создать тестовый файл с первыми 10K доменов
head -n 10000 woo_domains.txt > test_10k.txt

# Протестировать фильтрацию
./cPanelVulnFinder.sh test_10k.txt test_10k_filtered.txt

# Если работает - масштабировать на весь список
```

| Метод | Время | Сложность | Параллелизм |
|--------|-------|-----------|----------------|
| Без фильтрации | ~105 дней | Низкая | Нет |
| Ручное разбиение | ~2 часа | Средняя | 4 процесса |

## 🎯 После фильтрации:

```bash
# Все фильтрованные таргеты будут в:
filtered_results/all_vulnerable_targets.txt

# Сканировать с cPanelSniper
python3 cPanelSniper.py -l filtered_results/all_vulnerable_targets.txt \
    -t 50 -o results.json --resume

# Ожидаемое время сканирования:
# 10K таргетов × ~60 сек = ~17 часов (1 поток)
# 10K таргетов × ~12 сек = ~33 минут (50 потоков)
```

---

## 🔧 Настройки mass_filter.sh:

Редактируйте в начале скрипта:

```bash
INPUT_FILE="${1:-woo_domains.txt}"      # Входной файл
OUTPUT_DIR="filtered_results"         # Директория для результатов
SPLIT_SIZE=100000                    # Доменов на часть
PARALLEL_JOBS=8                       # Параллельных процессов
```

---

## 📈 Мониторинг прогресса:

```bash
# Если используете ручное разбиение - мониторить логи
tail -f filtered_parts/*_filtered.log

# Если используете mass_filter.sh - прогресс показывается автоматически
# или использовать монитор:
./monitor_progress.sh
```

---

## 💡 Советы:

1. **Начните с тестового файла** (10K доменов) - убедитесь, что все работает
2. **Используйте автоматический режим** (mass_filter.sh) - проще и быстрее
3. **Мониторьте прогресс** - не ждите молча
4. **Проверьте ресурсы** - 8 процессов требуют CPU и RAM
5. **Используйте --resume** в cPanelSniper - для больших списков
